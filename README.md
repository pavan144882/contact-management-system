# 📇 Contact Management System

A desktop Contact Management System built using Java Swing.

## 🚀 Features

- Add contacts
- Edit contacts
- Delete contacts
- Search contacts
- Sort contacts
- Phone number validation
- Email validation
- Duplicate phone number prevention
- Automatic file persistence
- Modern Java Swing GUI
- Double-click contact editing

## 🛠️ Technologies

- Java
- Java Swing
- OOP
- ArrayList
- File I/O
- JTable
